# Website Soul Monster — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `apps/web`, a separate Vite + TypeScript multi-page website (Beranda, Berita, Peringkat, Ensiklopedia, Panel Admin) on the game's Supabase project, plus the `web` edge function and its tables.

**Architecture:** Static multi-page site; live data comes only from one new edge function `web`. Pure rules (news visibility/validation, leaderboard ranking, public monster view) live in `packages/shared/src/web.ts` so the edge function and tests share them. The site never imports `gameData`: a generator script writes only the public data the site needs (`web.*` text, arena tiers, 5 featured monsters, per-tier counts) to `apps/web/src/generated/web-data.json`, so Altar recipes and locked monsters never reach the browser.

**Tech Stack:** TypeScript strict, Vite 6 (multi-page `build.rollupOptions.input`), Vitest, ESLint + Prettier, Supabase (Postgres, Auth via raw `fetch` like `apps/game/src/server.ts`, Storage, Edge Functions on Deno), pnpm workspaces.

**Spec:** [docs/superpowers/specs/2026-10-28-website-design.md](../specs/2026-10-28-website-design.md)

## Global Constraints

- Visual style **C · Epik Gelap**: background `#0b0a12`, gold accent `#ffc83d`, main button gradient `#ffd866 → #e0a21a`, panel `#16121e`, owned-monster border `#3ccf91`, font Fredoka 400/500 only (`@fontsource/fredoka`, as the game).
- All visitor text in Indonesian from `data/text.json` under `web.*` keys; monster names English from data. No visitor text hard-coded in `.ts`/`.html` except the brand "✦ SOUL MONSTER".
- Numbers (featured monster ids, cover size limit, leaderboard size 50, news per page) live in `data/rules.json → web`, validated by zod in `packages/shared/src/data/schema.ts` (CLAUDE.md rule 1, 3).
- `packages/shared` stays pure: no `Date.now()`, `Math.random()`, DOM (CLAUDE.md rule 2). Time is passed in.
- The site never imports `@soul-monster/shared`'s `gameData` at runtime; only `apps/web/src/generated/web-data.json` and pure functions/types that do not pull data.
- Every new logic function has a Vitest test (CLAUDE.md rule 4).
- **No commits.** Owner rule: changes stay uncommitted until the owner asks. Each task ends with a checkpoint (tests + lint for the touched files), not a commit.
- Before calling a task done: `pnpm test`, `pnpm lint`, `pnpm typecheck` pass; after edge-function changes also `pnpm build:server`.

## Review Focus

1. **Markdown with HTML/script in news body** (`<script>`, `<img onerror>`, `[x](javascript:alert(1))`) must render as harmless text/links — test in Task 3.
2. **Non-admin calling admin actions directly** (forged request to `news.publish` etc.) must get `forbidden`, and draft/hidden news must never appear in `news.list`/`news.get` — tests in Task 2 (pure rules) and Task 4 (handler routing).
3. **Player outside the top 50 / player with no arena snapshot this season**: the page shows their row below the list, or nothing (no error) — test in Task 2 (`rankLeaderboard`).
4. **Server unreachable or session expired**: Beranda still renders its static parts, Berita/Peringkat show "Belum bisa dimuat" with retry, expired session falls back to logged-out view silently — test in Task 5 (`loadSession` / `withFallback`).
5. **Recipe or locked-monster data in the shipped bundle** — test in Task 10 (bundle scan) and Task 1 (generator output has only allowed keys).
